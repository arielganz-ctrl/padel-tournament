# טופס הרשמה לטורניר פאדל

טופס הרשמה (כל שחקן בנפרד) שנשמר ישירות ל-Google Sheet בגוגל דרייב שלך. **חינם לגמרי**: אין שרת ואין מסד נתונים.

- `index.html`: דף הטופס (מתארח בחינם ב-GitHub Pages)
- `apps-script/Code.gs`: קוד קטן שרץ אצל גוגל ומוסיף כל הרשמה כשורה בגיליון

## התקנה (בערך 10 דקות)

### 1. יוצרים גיליון בדרייב
1. נכנסים ל-[sheets.new](https://sheets.new) ונותנים שם, למשל "הרשמות טורניר פאדל".
2. בתפריט: **תוספים (Extensions) ← Apps Script**.
3. מוחקים את מה שיש בעורך, מדביקים את כל התוכן של `apps-script/Code.gs` ושומרים (Ctrl+S).

### 2. מפרסמים כ-Web App
1. למעלה מימין: **Deploy ← New deployment**.
2. ליד "Select type" לוחצים על גלגל השיניים ובוחרים **Web app**.
3. מגדירים:
   - **Execute as:** Me
   - **Who has access:** Anyone
4. לוחצים **Deploy** ומאשרים הרשאות (גוגל יציג "האפליקציה לא אומתה": לוחצים Advanced ← Go to ... (unsafe). זה בסדר, כי זה הקוד שלך).
5. מעתיקים את ה-**Web app URL** (נגמר ב-`/exec`).

### 3. מחברים את הטופס
פותחים את `index.html`, ובבלוק `CONFIG` שבתחתית:
- מדביקים את הכתובת ב-`scriptUrl`
- מעדכנים תאריך, מקום, מחיר וקטגוריות

### 4. מעלים לאוויר בחינם (GitHub Pages)
ב-GitHub: **Settings ← Pages ← Branch: main / root ← Save**.
אחרי דקה הטופס זמין בכתובת `https://arielganz-ctrl.github.io/padel-tournament/`.

## שימושי
- **הגבלת מספר שחקנים:** ב-`Code.gs` משנים `MAX_PLAYERS = 0` למספר (למשל 32). כשהטורניר מלא הטופס יציג הודעה.
- **אחרי שינוי ב-Code.gs** צריך לעשות **Deploy ← Manage deployments ← עריכה ← Version: New version**, אחרת השינוי לא ייכנס לתוקף. הכתובת לא משתנה.
- **התראה במייל על כל הרשמה:** בגיליון, **Tools ← Notification settings**.
- ההרשמות נשמרות רק בגיליון שלך. אף אחד אחר לא יכול לקרוא אותן, גם לא דרך הטופס.
